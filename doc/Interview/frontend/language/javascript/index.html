JavaScript

约 156 字小于 1 分钟

2026-02-04

适用场景

Web 前端、Node.js 后端、全栈开发、浏览器脚本、跨平台应用（Electron/React Native）。

要点

  • 基础语法：变量、数据类型、运算符、控制流
  • 函数与作用域：闭包、this 绑定、箭头函数
  • 异步编程：Promise、async/await、事件循环
  • 原型与继承：原型链、ES6 class
  • DOM 操作与浏览器 API
  • ES6+ 新特性：解构、模块化、Symbol、Proxy 等

优缺点

优点：生态丰富、灵活性高、学习曲线平缓、跨平台支持好。
缺点：弱类型、运行时错误多、大型项目维护困难、性能相对较低。
