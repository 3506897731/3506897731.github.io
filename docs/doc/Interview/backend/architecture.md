# 架构

面试中常问：从单体到微服务、领域驱动与事件驱动等架构思路。

## 要点

- **单体 → 微服务**：拆分边界、服务发现、配置与部署
- **领域驱动（DDD）**：限界上下文、聚合、领域事件
- **CQRS**：读写分离、事件溯源与一致性
- **事件驱动**：消息队列、事件总线、最终一致性
- **BFF / 网关**：聚合、鉴权、协议转换与可观测

## 扩展

可结合「API 设计」「高可用」：架构如何影响接口形态，以及如何通过限流、熔断、降级保障高可用。
