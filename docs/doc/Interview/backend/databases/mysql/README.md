# MySQL

面试中常问：MySQL 存储引擎、索引、事务、锁与 SQL 优化。

## 内容导航

- [MySQL 语言规范](/doc/Interview/backend/language/mysql/coding-standards/)：命名、书写、建表/索引规约与常用约定

## 要点概览

- **存储引擎**：InnoDB、MyISAM 等；行锁、事务、MVCC
- **索引**：B+ 树、聚簇/非聚簇、覆盖索引、最左前缀
- **事务**：ACID、隔离级别、redo/undo、死锁
- **SQL 优化**：执行计划、慢查询、分页与批量
- **高可用**：主从、读写分离、分库分表思路
