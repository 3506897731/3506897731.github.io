# 语言与运行时

面试中常问：至少深入一门语言与对应运行时，能说清特性、生态与适用场景。

## 要点

- **Node.js**：事件循环、CommonJS/ESM、异步模型、性能与调试
- **Go**：协程、并发模型、标准库与工程实践
- **Rust**：所有权/借用、零成本抽象、生态（async、crates）
- **Java/Kotlin**：JVM、GC、Spring 等生态
- **Python**：GIL、类型注解、异步与常用框架

## 扩展

可结合「API 设计」「架构」「高可用」一起准备：语言选型如何影响接口设计、可观测性与容错。
