# Rust

## 适用场景

系统组件、高性能中间件、WebAssembly、嵌入式、与 C/FFI 交互、对安全与性能要求高的服务。

## 要点

- 所有权、借用与生命周期、Send/Sync
- 泛型、trait、错误处理（Result/Option）、异步（async/await）
- 生态：async runtime、crates、与 C 互操作

## 优缺点

**优点**：内存安全无 GC、零成本抽象、并发安全。  
**缺点**：学习曲线陡、编译慢、生态相对年轻。
