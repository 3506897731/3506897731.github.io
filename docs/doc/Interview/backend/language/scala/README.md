# Scala

## 适用场景

JVM 上的函数式+面向对象、大数据（Spark）、高并发/响应式（Akka）、DSL 与领域建模。

## 要点

- 函数式：不可变、高阶函数、Option/Either、for 推导
- 面向对象：trait、模式匹配、隐式（implicit）
- 生态：Spark、Akka、Play、Cats 等

## 优缺点

**优点**：表达力强、与 Java 互操作、Spark/Akka 等生态。  
**缺点**：学习曲线陡、编译慢、社区相对小。
