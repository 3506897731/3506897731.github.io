# 后端与服务端

语言与运行时、API 设计、架构与高可用相关面试要点。

## 内容导航

- **语言与运行时**：Node.js、Go、Rust、Java/Kotlin、Python 等至少一门深入
- **API 设计**：REST、GraphQL、RPC、版本化、鉴权（JWT/OAuth2）
- **架构**：单体 → 微服务、领域驱动（DDD）、CQRS、事件驱动
- **高可用**：限流、熔断、降级、重试、幂等、分布式事务思路
