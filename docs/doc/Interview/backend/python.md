# Python

## 适用场景

数分/ML/AI、脚本与自动化、粘合剂、Django/FastAPI 中小型 Web、运维与爬虫。

## 要点

- 语言特性：GIL、类型注解、异步（asyncio）、上下文管理器
- 生态：NumPy/Pandas、ML/AI 库、Django/FastAPI、Celery
- 工程：虚拟环境、打包、与 C 扩展

## 优缺点

**优点**：上手快、库多、AI 生态强。  
**缺点**：GIL 限制多线程 CPU 并行，性能与类型需靠规范与工具补强。
