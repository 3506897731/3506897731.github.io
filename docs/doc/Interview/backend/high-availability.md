# 高可用

面试中常问：如何通过限流、熔断、降级、重试与幂等保障系统可用性与一致性。

## 要点

- **限流**：令牌桶、漏桶、滑动窗口；全局限流与多级限流
- **熔断**：熔断状态、半开与恢复策略
- **降级**：功能降级、读降级、兜底数据与开关
- **重试**：退避策略、幂等设计与重复请求处理
- **分布式事务**：两阶段、TCC、Saga、本地消息表等思路

## 扩展

可结合「架构」「API 设计」：在微服务与事件驱动架构下，如何设计接口与调用链以配合限流、熔断与降级。
