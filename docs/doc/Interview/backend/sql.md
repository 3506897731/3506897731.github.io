# SQL

## 适用场景

关系型数据存储与查询、报表与分析、OLTP/OLAP、数据建模与约束、与各类数据库/数仓配合。

## 要点

- DDL：表、索引、约束、分区
- DML：SELECT、JOIN、聚合、窗口函数、子查询
- 事务与隔离级别、锁与并发、执行计划与优化
- 方言差异：PostgreSQL、MySQL、Oracle、SQL Server 等

## 优缺点

**优点**：声明式、标准化、与各类存储/数仓兼容。  
**缺点**：复杂分析需优化，方言差异需注意。
