# Java / Kotlin

## 适用场景

企业级后端、Spring 生态、Android、大数据（Spark/Flink）、高吞吐稳定服务。

## 要点

- **Java**：JVM、GC、并发（synchronized、JUC）、Spring 生态
- **Kotlin**：空安全、协程、与 Java 互操作、Android 首选
- 共同：字节码、类加载、反射、注解

## 优缺点

**优点**：JVM 成熟、工具链与监控完善、人才多。  
**缺点**：启动与内存占用较大，Java 语法相对冗长，Kotlin 更简洁。
