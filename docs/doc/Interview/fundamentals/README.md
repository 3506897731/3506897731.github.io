# 基础与计算机原理

数据结构与算法、操作系统、计算机网络、数据库等计算机基础与原理相关知识点。

## 内容导航

- **数据结构与算法**：数组、链表、树、图、哈希表；排序、搜索、动态规划、贪心、回溯
- **操作系统**：进程/线程、内存管理、虚拟内存、调度、死锁、I/O、协程
- **计算机网络**：TCP/IP、HTTP/HTTPS、WebSocket、REST、gRPC、CDN、负载均衡
- **数据库**：关系型（SQL、事务、索引、锁）、NoSQL（文档/键值/图）、CAP、一致性模型
