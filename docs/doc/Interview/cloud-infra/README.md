# 云与基础设施

容器与编排、CI/CD、云服务与可观测性相关面试要点。

## 内容导航

- **容器与编排**：Docker、Kubernetes（Pod/Service/Ingress、Helm）
- **CI/CD**：GitHub Actions、GitLab CI、Jenkins、流水线设计
- **云服务**：AWS/GCP/阿里云等（计算、存储、消息队列、函数计算）
- **可观测性**：日志、指标、链路追踪（如 OpenTelemetry）、告警
