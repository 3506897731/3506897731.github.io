# TypeScript

## 适用场景

大型前端/全栈工程、类型安全需求高的项目、与 JS 生态兼容的 Node/Deno 后端、React/Vue/Angular 等现代框架。

## 要点

- 类型系统：接口、泛型、联合/交叉类型、类型推断与断言
- 与 JavaScript 互操作、声明文件（.d.ts）、tsconfig
- 工程化：编译、增量构建、与打包工具集成

## 优缺点

**优点**：类型安全、IDE 体验好、与 JS 生态无缝兼容。  
**缺点**：需编译步骤、配置与类型学习成本。
