# 前端语言

:::: card-grid

::: card title="JavaScript" icon="logos:javascript"

**适用场景**：Web 前端、Node.js 后端、全栈开发、浏览器脚本、跨平台应用（Electron/React Native）。

**优缺点**：生态丰富、灵活性高、学习曲线平缓；弱类型、运行时错误多、大型项目维护困难。

[More →](/doc/Interview/frontend/language/javascript/)
:::

::: card title="TypeScript" icon="logos:typescript-icon"

**适用场景**：大型前端/全栈工程、类型安全需求高的项目、与 JS 生态兼容的 Node/Deno 后端、React/Vue/Angular 等现代框架。

**优缺点**：类型安全、IDE 体验好、与 JS 生态无缝兼容、重构更安全；需编译步骤、配置与类型学习成本。

[More →](/doc/Interview/frontend/language/typescript/)
:::

::::
