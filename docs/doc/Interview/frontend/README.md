# 前端

HTML/CSS/JS、框架、工程化与体验相关面试要点。

## 内容导航

- **核心**：HTML/CSS/JS、ES6+、TypeScript、DOM、事件、性能优化
- **框架**：React / Vue / Svelte（组件化、状态管理、虚拟 DOM、SSR/SSG）
- **工程化**：打包（Vite/Webpack）、模块化、Tree-shaking、代码分割、PWA
- **体验与规范**：无障碍、安全（XSS/CSRF）、Web 标准、浏览器兼容
