# Angular

## 适用场景

企业级大型应用、复杂业务系统、需要完整解决方案的项目、TypeScript 优先的团队。

## 要点

- 组件与模块系统
- 依赖注入（DI）
- RxJS 与响应式编程
- 路由与导航
- 表单处理（模板驱动与响应式）
- HTTP 客户端与拦截器
- 变更检测机制

## 优缺点

**优点**：完整的框架生态、TypeScript 原生支持、企业级工具链、依赖注入设计优秀。  
**缺点**：学习曲线陡峭、打包体积较大、概念较多较复杂。
